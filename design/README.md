# Design — refonte UI « Néon Diner »

Sources livrées par Claude Design, conservées telles quelles comme référence.
Ne pas les charger dans le jeu : le script `scripts/import-assets.mjs` produit les versions
nettoyées dans `src/assets/`.

- `BRIEF_INTEGRATION_UI.md` : brief d'intégration (fait foi avec les planches).
- `CDC_refonte_UI_UX.pdf` : cahier des charges d'origine.
- `planches/` : piste A, kit et décor, maquettes.
- `pack/tokens.css` : couleurs, rayons, polices.
- `pack/equipements|monde|icones|ui/` : SVG sources.
- `pack/ecrans/` : écrans de référence 390 × 844 (jamais intégrés comme images).
